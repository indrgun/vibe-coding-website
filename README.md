# Daily Scripture — KJV Bible Verses

An interactive React site featuring King James Version Bible verses with an animated celestial background. Verses are periodically fetched from the [bible-api.com](https://bible-api.com) API.

## Features

- Animated gradient background with floating particles, twinkling stars, and light rays
- Auto-rotating Bible verses every 30 seconds
- Smooth fade transitions between verses
- Pause/resume and manual "Next Verse" controls
- Countdown progress bar
- Fully responsive design
- Optimized for Vercel deployment

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy on Vercel

Push to GitHub and import at [vercel.com/new](https://vercel.com/new). Zero configuration required — Next.js is auto-detected.

## Tech Stack

- **Next.js 15** (App Router)
- **React 19**
- **TypeScript**
- **Tailwind CSS v4**
- **bible-api.com** (KJV translation)
